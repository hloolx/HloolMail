# v0.8.1

## 优化改进

- 控制台默认改用系统字体，减少首屏对外部字体服务的依赖，也避免严格安全策略下的字体加载告警。
- 调整默认内容安全策略，兼容当前前端组件运行时样式、Cloudflare Turnstile 和可选的 Cloudflare Insights 统计脚本。

## 修复问题

- 修复未登录或会话失效时，控制台反复探测 `/api/auth/me`，可能连续返回 `401` 并最终触发 `429 Too Many Requests` 的问题。
- 修复生产环境 CSP 会拦截 Google Fonts、Cloudflare Insights 和部分运行时样式，导致浏览器控制台持续报错、界面样式可能异常的问题。

## 部署说明

- 本次目标版本为 `0.8.1`，发布 tag 为 `v0.8.1`。
- 本版本不包含数据库迁移，现有 `v0.8.0` 部署可直接升级。
- 如果部署层额外覆盖了 `Content-Security-Policy` 响应头，请同步允许当前版本的控制台运行时样式和 Cloudflare 相关资源。
