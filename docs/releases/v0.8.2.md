# v0.8.2

## 新增功能

- 新增可选的前端错误与性能监控配置，支持通过环境变量接入兼容 Sentry 的监控服务，并记录关键 Web Vitals。
- 新增生产构建 canonical URL 配置，只有设置 `VITE_CANONICAL_URL` 时才输出 canonical。
- 新增前端构建分析入口，便于排查包体积和依赖拆分。

## 优化改进

- 升级前端构建工具链并优化依赖拆包，降低核心页面加载和后续导航的抖动。
- 优化控制台状态订阅，减少通知、侧栏、顶部栏等高频状态变化带来的不必要重渲染。
- 优化管理后台页面框架，支持统一的加载、错误、重试和面包屑呈现。
- 优化收件箱、验证码复制、域名和安装流程的前端内部结构，提升页面响应稳定性。
- 增加前端运行时配置示例，并补充 Node.js 版本和 canonical 配置说明。

## 修复问题

- 修复管理员侧栏菜单较长或窗口高度较小时，左下角用户信息卡片可能被挤压或裁切的问题。
- 修复未配置公开域名时静态 canonical 指向 `/`，可能影响搜索引擎收录判断的问题。
- 改善前端异常上报过滤，避免登录过期、业务校验和取消请求产生误报。

## 部署说明

- 本次目标版本为 `0.8.2`，发布 tag 为 `v0.8.2`。
- 前端构建环境需要 Node.js `^20.19.0 || >=22.12.0`；CI 和 Docker 构建使用 Node 22。
- 如需启用前端监控，请在构建前设置 `VITE_SENTRY_DSN`，可选设置 `VITE_APP_VERSION=0.8.2` 和 `VITE_APP_ENV=production`。
- 如需输出 canonical，请在构建前设置 `VITE_CANONICAL_URL` 为站点公开访问地址。
- 本版本不包含数据库迁移，现有 `v0.8.1` 部署可直接升级。
- 按用户要求，本次跳过本地测试和构建验证。
