# v0.9.2

## 优化改进

- 优化控制台侧边栏选中态，当前导航项使用更明确的黑字、近白底、细边框和轻阴影，未选中项降为更浅的灰黑色。
- 管理员首次进入控制台时默认使用收起侧边栏，已有手动偏好的浏览器仍会保留原选择。
- 调整侧边栏收起态的图标轨道，扩大稳定命中区域并让图标严格居中，主内容左边界保持整齐。
- 优化折叠菜单浮层和暗色模式下的选中态表现。

## 修复问题

- 修复侧边栏收起后隐藏文字仍占用 flex 布局空间，导致图标视觉上偏左的问题。
- 修复侧边栏选中项背景过淡、点击反馈不够清晰的问题。

## 部署说明

- 本次版本为 `0.9.2`，发布 tag 为 `v0.9.2`。
- 按要求跳过本地测试与构建验证，发布后以 GitHub Actions 结果为准。
