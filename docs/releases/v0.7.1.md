# v0.7.1

## 修复问题

- 修复使用 PostgreSQL 部署时，启动迁移可能因为 `message_daily_stats.message_count` 字段引用歧义而失败的问题。受影响实例会在启动日志中看到 `column reference "message_count" is ambiguous`，并导致服务停止。
- 修复每日邮件统计回填和新增邮件计数使用同类 upsert 表达式时的潜在 PostgreSQL 兼容性问题，避免迁移通过后在后续收信统计中再次触发相同错误。

## 优化改进

- 为每日邮件统计的 PostgreSQL upsert SQL 增加生成断言，确保维护过程中不会重新引入未限定字段引用。

## 部署说明

- 本次为小版本维护补丁，目标版本为 `0.7.1`，发布 tag 为 `v0.7.1`。
- 本次按用户要求跳过本地验证；推送 `main` 与 `v0.7.1` tag 后，由 GitHub Actions 完成 CI、Docker 镜像发布和 Release 二进制重新打包。
- PostgreSQL 部署可直接从 `v0.7.0` 升级到 `v0.7.1`。升级后服务启动时会重新执行迁移检查，已存在的邮件每日统计会保留，并按实际历史邮件数量补齐。
