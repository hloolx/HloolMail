# v0.3.0

## 新增功能

- 管理后台新增全局分享链接与 Webhook 管理能力，管理员可以集中查看、排查和管理系统级分享与投递记录。
- 新增注册邮件投递状态跟踪，管理员测试 SMTP 配置后可以看到邮件是否排队、成功或失败。
- 新增默认头像资源与昵称展示优化，让用户列表、个人资料和头像显示更稳定。

## 优化改进

- 优化注册与登录设置页，已保存的 SMTP 密码不再直接填入输入框，避免误把占位符当成真实密码。
- 优化 Docker Compose 部署变量，使用 `HLOOLMAIL_DATABASE_URL`、`HLOOLMAIL_FRONTEND_DIST` 等专用变量，减少本地开发 `.env` 对容器部署的干扰。
- 优化 Docker 镜像构建流程，发布镜像会写入版本号、提交号和构建时间，便于排查线上运行版本。
- 优化发布流程，GitHub Release 会读取本次中文发布说明，方便用户直接了解变化。

## 修复问题

- 修复登录、注册校验、Passkey 登录、用户列表和个人资料接口可能返回不必要用户字段的问题，避免头像地址等内部字段被公开暴露。
- 修复管理员 Webhook 投递列表中失败原因不清楚的问题，现在会优先显示错误信息，没有错误时显示响应内容。
- 修复前端昵称校验触发 lint 错误的问题，保留控制字符拦截能力，同时让构建检查通过。
- 修复 Docker Compose 默认 PostgreSQL 密码过弱仍可继续启动的风险，部署时必须设置自己的强密码。

## 部署说明

- Docker Compose 部署请复制 `.env.compose.example` 为 `.env` 后再填写，不要复用本地开发 `.env`。
- 使用 Compose 内置 PostgreSQL 时必须设置 `POSTGRES_PASSWORD`，不要使用默认示例值。
- 如需连接外部 PostgreSQL，请设置 `HLOOLMAIL_DATABASE_URL`，不要再使用通用 `DATABASE_URL`，并使用 `docker compose up -d app` 只启动应用服务。
- 发布后建议确认 GitHub Actions、GitHub Release 和 GHCR Docker 镜像都完成生成。
