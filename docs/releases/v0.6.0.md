# v0.6.0

## 新增功能

- 管理后台升级为独立的运营概览、DNS 检查、域名健康、额度告警、API 接口、分享链接治理、Webhook 治理和审计日志页面，管理员可以从侧边栏直接进入对应模块。
- 收件箱、邮件详情和公开分享邮件现在会识别常见验证码，并提供一键复制按钮，减少从邮件正文里手动查找验证码的步骤。
- 收件箱新增发件人品牌头像识别，常见服务商邮件会显示更清晰的品牌标识，普通发件人继续使用稳定的默认头像。

## 优化改进

- 管理后台的数据请求、缓存刷新和页面切换逻辑更集中，页面加载更轻量，旧的 `#/admin?tab=...` 链接会自动映射到新的管理页面。
- 表格组件新增加载骨架、错误重试、移动端卡片布局、可排序表头和隐藏列空状态，用户、API 密钥、域名、Webhook 等列表在窄屏下更容易扫描和操作。
- 通知中心会在收到新邮件时刷新邮箱、邮件列表和统计数据，切回收件箱时能更快看到最新邮件。
- 登录设置、DNS 设置和 API 接口设置增加未保存修改提醒，减少切换页面时误丢配置的风险。
- 页面过渡动画统一为共享组件，并兼容系统的减少动态效果偏好。

## 修复问题

- 修复邮件验证码可能被订单号、运单号、日期等误判的问题，并在后端响应中直接返回更可靠的 `verification_code` 字段。
- 修复域名模式切换时全表按钮一起进入忙碌状态的问题，现在只锁定正在更新的域名。
- 修复用户额度和 SMTP 端口配置可以提交非法数字的问题，非法输入会在保存或测试邮件前被拦截。
- 修复确认弹窗在异步删除或禁用操作期间仍可重复点击、关闭或触发二次操作的问题。

## 部署说明

- 本版本不包含数据库迁移，也没有新增必填环境变量。
- 发布 `v0.6.0` tag 后，GitHub Actions 会在云端完成 CI、Docker 镜像发布和 Release 二进制打包。
