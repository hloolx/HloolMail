# v0.9.1

## 优化改进

- 重做控制台侧边栏布局，采用更稳定的固定侧栏、内容区内缩和折叠图标栏结构，展开和收起时页面边距更整齐。
- 折叠侧边栏中的分组菜单改为右侧浮层展开，子菜单可直接选择，不再挤压主内容区。
- 将账号信息入口移到顶部头像菜单，侧边栏底部不再堆放用户卡片，导航区域更清爽。
- 优化移动端侧边栏抽屉表现，切换桌面和移动端时自动清理抽屉状态。
- README 增加并嵌入项目插图，方便新用户快速理解私有邮箱网关、部署、DNS 路由和自动化投递场景。

## 修复问题

- 修复侧边栏收缩后图标轨道、主内容左边界和分组菜单浮层容易显得错位的问题。
- 修复控制台主内容依赖硬编码左侧 padding 导致不同侧边栏状态下间距不一致的问题。

- 本次版本为 `0.9.1`，发布 tag 为 `v0.9.1`。
- 按要求跳过本地测试与构建验证，发布后以 GitHub Actions 结果为准。
