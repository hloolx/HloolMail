# v0.5.0

## 新增功能

- 新增 YYDS Mail 兼容层，管理员开启后可通过 `/yyds/v1` 使用兼容方式调用临时邮箱能力。
- 新增管理员“API 接口管理”页面，可集中控制 YYDS 兼容层开关；关闭时兼容路径返回 404，且不会消耗 API Key 额度。
- 新增独立 DTO 转换层，将 YYDS 风格的账户、域名、消息、消息源和已读状态请求转换到现有邮箱与邮件逻辑。
- API 文档页在兼容层开启时仅显示支持状态和接口地址 `/yyds/v1`，不提供兼容端点测试入口。

## 优化改进

- YYDS 兼容层复用现有 API Key 认证、额度消耗、邮箱归属、私有域名权限、邮件读取和删除逻辑，避免引入第二套账户体系。
- API 文档、OpenAPI、Skill 文档和接口调试器继续保持 `/api/` 自动化边界，不向 AI 可读文档暴露 YYDS 兼容端点。
- 未注册的 `/yyds/v1` 路径现在稳定返回 JSON 404，不会落到前端页面。
- 管理员审计日志新增 API 接口设置变更记录，方便追踪兼容层开关操作。

## 修复问题

- 修复 YYDS 兼容层关闭时可能被普通 API Key 中间件提前消耗额度的风险。
- 修复存在前端静态页面时，未知 `/yyds/v1/*` 路径可能返回 HTML 的问题。

## 部署说明

- 本次发布会新增 `api_interface_settings` 数据表，用于保存 YYDS 兼容层开关，默认关闭。
- 发布后如需兼容 YYDS Mail 调用方式，请管理员在 Web 控制台的“API 接口管理”中开启兼容层。
- 兼容层仍使用本系统 API Key，不会启用 YYDS 临时 Bearer Token、AI 代理或 Webhook 管理能力。
