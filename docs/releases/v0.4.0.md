# v0.4.0

## 新增功能

- 新增全站仪表盘，管理员可以集中查看邮箱、邮件、域名、用户、API 调用和增长趋势。
- 新增管理员趋势统计，支持按 7 天、30 天、90 天查看新增邮箱、邮件、域名、用户和 API 调用。
- 新增风险与待办入口，将域名健康、额度预警、配置风险和 DNS 检测状态集中展示，并可直接跳转处理。
- 新增用户新手引导开关。开启后，新注册普通用户会按步骤完成公开域名、邮箱、API 密钥和 API 文档探索。
- 新增用户引导进度接口，支持完成、跳过和根据站点额度策略自动判断下一步。
- 分享链接返回邮箱地址，管理员和用户在查看分享链接时更容易识别对应邮箱。

## 优化改进

- 管理首页重新整理为更清晰的全站概览，补充公开/私有域名、公开/私有邮箱、管理员/普通用户、启用/禁用状态等结构化指标。
- API 文档探索器优化已保存 API Key 的选择和揭示流程，避免切换接口时误清空密钥，并在密钥加载中禁用发送按钮。
- 域名添加、邮箱创建、API Key 创建和 API 文档页面接入新手引导高亮，让首次使用路径更连贯。
- 统计时间范围扩展到最长 90 天，便于管理员观察更长周期的增长变化。
- API 使用日志改为先复制请求上下文再异步写入，提升日志记录稳定性并保留失败日志。

## 修复问题

- 修复搜索条件中 `%`、`_`、反斜杠会被当作通配符的问题，域名、用户、API Key、审计日志、Webhook 和分享链接搜索现在按字面量匹配。
- 修复生产环境密钥校验不够严格的问题，现在会拒绝过短或默认的 `INBOX_TOKEN_SECRET`，并要求它与 `SESSION_SECRET` 不同。
- 修复 SMTP 服务暴露不需要的 AUTH 能力的问题，避免客户端误以为该服务支持 SMTP 认证。
- 修复邮件主题、发件人等文本截断时可能按字节长度误判多字节字符的问题。
- 修复数据库迁移回填消息归属时对列名缺少校验的问题，避免异常列名进入 SQL 拼接。
- 修复跨站上下文下会话读取边界不够严格的问题，收件箱流式读取现在要求同源会话请求。

## 部署说明

- 本次发布包含数据库字段新增，会通过现有迁移自动增加用户引导状态和系统引导开关。
- 生产环境部署前请确认 `SESSION_SECRET` 与 `INBOX_TOKEN_SECRET` 均为不同的随机长密钥。
- 发布后可在管理员额度设置中开启“用户新手引导”，已有用户不会被强制重新引导。
