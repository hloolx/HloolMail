# v0.9.0

## 新增功能

- 控制台侧边栏新增管理员分组导航，可按账户与额度、运营监测、治理工具、系统设置展开或收起，长菜单下更容易定位功能。
- 邮件列表、邮件详情、共享收件箱详情和登录区域增加骨架屏加载状态，弱网或首次加载时界面反馈更稳定。

## 优化改进

- 首页首屏、功能卡片、API 展示区和统计信息完成视觉优化，品牌信息更集中，功能入口更清晰。
- 首页顶部状态条在滚动时保持固定位置，并根据当前段落稳定高亮“使用流程、功能特性、适用场景、自部署”。
- 首页底部改为简洁版权与 GitHub 仓库入口，移除重复的流程、特性和部署栏目。
- 控制台改为按页面加载样式和主界面代码，减少非当前页面资源对首屏的影响。
- 邮件发送方头像图片改为懒加载和异步解码，降低列表滚动时的渲染压力。

## 修复问题

- 修复首页点击“适用场景”和“自部署”后地址变化但导航高亮丢失或短暂闪回的问题。
- 修复页面切换动画影响固定定位元素，导致首页顶部状态条滚动后离开视口的问题。
- 修复首页源码中异常字符导致构建工具无法按 UTF-8 加载页面的问题。

## 部署说明

- 本次版本为 `0.9.0`，发布 tag 为 `v0.9.0`。
- 本次只包含前端体验和导航结构优化，不包含数据库迁移。
- 按用户要求，本次发版跳过本地测试和构建验证步骤。
