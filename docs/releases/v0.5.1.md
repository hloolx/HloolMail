# v0.5.1

## 新增功能

- 新增 `PUBLIC_INDEXING` 部署开关，可在 `none`、`landing`、`docs` 三种公开索引策略之间切换。
- 新增动态 `robots.txt` 和 `sitemap.xml` 生成逻辑，默认只让公开首页进入 sitemap，恢复信誉后才开放公开 API 文档入口。
- 新增 Safe Browsing 风险控制文档，覆盖部署默认值、反向代理检查、Chrome 标记后的排查和复审流程。

## 优化改进

- 登录页、安装页、控制台、分享页、用户数据 API 和带 `key` / `api_key` 的 URL 会返回 `X-Robots-Tag: noindex, nofollow, noarchive`。
- 前端公开文案和首页 meta 已调整为邮件收信、域名管理和测试环境定位，减少搜索引擎误判为高风险用途的概率。
- Docker Compose、`.env.example` 和安装流程已同步支持 `PUBLIC_INDEXING`，容器部署默认使用 `landing` 策略。

## 部署说明

- 新部署建议保持 `PUBLIC_INDEXING=landing`。
- 如果域名正在处理 Chrome 或 Safe Browsing 标记，建议临时改为 `PUBLIC_INDEXING=none`，重启服务并清理 CDN 或反向代理缓存。
- 只有在 Search Console 和 Safe Browsing 状态稳定后，才建议改为 `PUBLIC_INDEXING=docs` 开放公开文档索引。
