# v0.7.2

## 优化改进

- 优化分享链接页的“创建邮箱分享”体验：创建时可以直接复用收件箱里的“我的邮箱”列表，不再只能依赖前 50 个邮箱候选。
- 创建分享时支持按邮箱地址搜索、分页浏览和点击选择邮箱，邮箱数量较多时也能准确找到目标邮箱。
- 保留手动填写数字 mailbox ID 的方式，适合已经知道邮箱 ID 的场景；选择邮箱和手动 ID 会自动互斥，避免误选。
- 调整创建弹窗在桌面和移动端的布局，移动端默认可见底部操作按钮，邮箱列表在弹窗内滚动。

## 部署说明

- 本次为体验优化补丁，目标版本为 `0.7.2`，发布 tag 为 `v0.7.2`。
- 按用户要求跳过本地验证；推送 `main` 与 `v0.7.2` tag 后，由 GitHub Actions 完成 CI、Docker 镜像发布和 Release 二进制打包验证。
- 后端接口和数据库结构没有变化，可直接从 `v0.7.1` 升级到 `v0.7.2`。
