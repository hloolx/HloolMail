# v0.5.2

## 新增功能

- 普通用户现在可以从顶部工具栏重新打开新手教程，随时回顾邮箱创建、API 密钥申请和 API 文档使用流程。

## 优化改进

- 优化新手教程的遮罩、高亮和浮层层级，让当前步骤目标更清楚，减少被页面布局遮挡的情况。
- 调整 API 文档中的教程定位点，教程引导到接口调试区域时更准确。
- 改进顶部设置菜单在不同权限和窄屏场景下的排版，减少按钮和文字拥挤。

## 修复问题

- 修复重新体验教程时无法按普通浏览流程逐步关闭或继续的问题。
- 修复部分教程步骤完成状态和重播状态混在一起，可能影响用户已完成引导记录的问题。

## 部署说明

- 本版本不涉及数据库迁移或新的环境变量。
- 更新前端静态资源后即可生效；GitHub Actions 会在 tag 发布后自动构建 Release 产物和 Docker 镜像。
