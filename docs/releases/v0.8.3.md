# v0.8.3

## 优化改进

- 统一控制台侧栏在桌面端和移动端的断点判断，减少窗口缩放、浏览器缩放或首屏加载时侧栏状态不一致的情况。
- 增加侧栏布局回归检查，后续调整导航菜单或响应式行为时更容易发现用户信息卡片被挤压的问题。

## 修复问题

- 修复仪表盘桌面端首次进入时，左下角用户信息卡片可能不显示，切换到其他页面后才恢复的问题。
- 修复管理员菜单较长或窗口高度较小时，侧栏底部用户信息卡片可能被导航菜单挤出可视区域的问题。

## 部署说明

- 本次版本为 `0.8.3`，发布 tag 为 `v0.8.3`。
- 本次只包含前端控制台布局修复，不包含数据库迁移。
- 按用户要求，本次发版跳过本地验证步骤，直接提交并打 tag。
