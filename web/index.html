HLOOL Mail 自托管临时邮箱与私有域名收信平台

HLOOL Mail 用来搭建自部署、支持多用户的匿名邮箱和私有域名收信服务。把域名 MX 指向你的 HLOOL Mail 收信主机后，即可为团队、脚本、测试平台、CI 或 AI 助手提供可控的收信能力。

核心能力

  • SMTP catch-all 收信和 Web Console 邮箱管理。
  • API Key 自动生成邮箱、读取邮件和轮询验证码。
  • Webhook 在新邮件到达后投递到自动化系统。
  • Share Link 安全分享邮箱收件箱给外部访问者。
  • Docker、二进制和 CLI 部署方式。

适用场景

适合需要自托管临时邮箱、私有域名邮箱、邮箱 API、测试验证码收信、自动化账号注册、CI 邮件校验和 AI 助手邮件读取的团队。
